# 視野マッパー

レーベル遺伝性視神経症（LHON）などで中心が見えづらい方向けに、
「視野内のどの場所で、どの大きさの刺激に気付けるか」を簡易的に
測定・可視化するWebアプリです。

> ⚠️ 医療機器ではありません。結果は目安であり、診断には使えません。
> 正確な評価は眼科での視野検査を受けてください。

## 使い方

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

1. **準備** — 画面から約20cmの距離をとり、測定する眼（右眼・左眼・両眼）を
   選びます（距離は20cm固定）。
   初回は「画面の大きさを合わせる」で、カードを使って画面の実寸を合わせます
   （下記）。
2. **測定** — 画面中央の赤い丸を見続けます。固視点から視角2.5°・5°・10°・15°の
   4つの同心円上に、合計56箇所の固定地点があります（2.5°は8方向、それ以外は
   16方向）。各地点を1回ずつ、全56試行をランダムな順番で表示し、円に
   気付いた時点でEnterを押します。
   Enterと同時に次の地点で拡大が始まります。Escでいつでも中止できます。
3. **結果** — 各地点で気付いた円の半径から、56箇所の値を滑らかに補間した
   グラデーションマップを表示します。濃い赤ほど、その位置で
   気付くまでに大きな刺激が必要だったことを示します。結果は自動的に
   測定履歴へ保存されます。

固視が外れにくいよう、円は測定中の1個だけを表示します。円は半径0から
1秒あたり視角0.15°の速さで、全地点同じく最大半径5°まで拡大します。
内側の地点では円が中心の赤い丸（半径0.75°）に重なりますが、赤い丸は
白い縁付きで円の手前に描くので見失いません。

測定地点は画面の大きさではなく**視角（度）で固定**しているため、端末や
ウィンドウの大きさが違っても同じ網膜上の位置を測定します（範囲は
中心15°）。片眼の測定では、耳側15°付近の地点が生理的な盲点（マリオット
盲点）に重なるため、健常な眼でも気付きにくくなります。
最外周の円が最大まで広がっても画面から
欠けない大きさが必要で、ウィンドウが小さいと測定を一時停止して案内と
「全画面表示にする」ボタンを表示します。広げると、その地点を最初から
やり直します。試行ごとに地点は
変わりますが、測定に使う56箇所そのものは毎回同じです。

設定画面の「結果のサンプル」で、測定せずに結果画面のイメージを確認できます。

## 画面の大きさを合わせる（キャリブレーション）

視角を正しく表示するには、画面上の1mmが何ピクセルかを知る必要があります。
クレジットカード・キャッシュカード・マイナンバーカードなど、国際規格
（ID-1、85.60 × 53.98 mm）のカードを画面に当て、青い四角の大きさを
カードにぴったり合わせます（ボタン、スライダー、← → キーで調整）。

合わせた値はブラウザのlocalStorageに保存され、次回からはそのまま使います。
ブラウザの表示倍率（ズーム）や画面の大きさが変わったことを検知すると、
測定の前にもう一度合わせ直してもらいます。測定結果には、そのとき使った
1mmあたりのピクセル数も記録されます。

## 測定履歴

測定が完了すると結果はブラウザのlocalStorageに保存されます（最大300件、
古いものから削除）。設定画面・結果画面の「測定履歴」から過去の結果の
表示・削除ができます。

### 書き出し・読み込み（バックアップ）

履歴は端末のブラウザ内にしかないため、ブラウザのデータ消去や端末の変更で
失われることがあります。測定履歴の画面で、記録をJSONファイルとして
書き出せます。

- **すべて書き出す** — 全件を1つのファイルにまとめます
  （`visual-field-history-YYYYMMDD-HHMM.json`）。
- 各記録の **書き出す** — その1件だけを書き出します
  （`visual-field-YYYYMMDD-HHMM-right.json` など。日時は測定日時）。
- **ファイルから読み込む** — 書き出したファイルを履歴に戻します。
  すでに履歴にある記録（同じID）は二重に追加しません。形式が正しくない
  記録は読み込みません。読み込むと300件を超える場合は、古い記録が
  削除されることを確認してから読み込みます。

読み込んだ記録は通常の履歴と同じく「表示」で結果マップを見られます。

ファイルの形式:

```json
{
  "format": "visual-field-mapper-history",
  "version": 1,
  "exportedAt": "2026-10-23T05:30:00.000Z",
  "records": [
    {
      "id": "…",
      "savedAt": "…",
      "settings": { "distanceCm": 20, "pxPerMm": 3.78, "eye": "right" },
      "results": [{ "xDeg": 2.5, "yDeg": 0, "radiusDeg": 1.2, "sampleCount": 1, "maxRadiusDeg": 5 }]
    }
  ]
}
```

## 見え方の体験（健常者向け）

測定結果をもとに、LHONの方の見え方を健常者が体験できる画面です。
測定履歴の各記録の「体験する」から開きます。書き出したJSONを読み込めば、
患者さんに測定してもらった結果で体験できます。

- コードエディタ風・文書作成ソフト風の画面を表示し、マウスのカーソルの
  まわりに、測定結果の見えにくさを再現します。体験する人にはカーソルの先を
  見続けてもらい、カーソルを視線の代わりにします。
- 見えにくい場所ほど、強いぼかし・色の薄れ・コントラストの低下を重ねます。
- 見えにくい範囲は視角で決め、今の画面の大きさ（キャリブレーション）と
  「画面までの距離」（15〜60cm、既定20cm）からピクセルに直します。視力が低い
  LHONの方は、画面に近づいて20cmほどで見ることが多いため、20cmを既定にしています。画面の大きさを
  合わせていない場合、範囲の大きさは目安になります。
- 「文字の拡大」で、コードや文書の本文を100〜1500%（既定700%）に拡大できます。
  LHONの方は文字をかなり大きくして使う（協力いただいた方は500%より大きくして
  いた）ため、実際のアプリの大きさより大きくしています。文書ページの余白は
  拡大せず、文字に使える幅を確保します。実際のアプリと同じく、拡大するのは本文だけで、
  サイドバーやメニューは元の大きさのままです。
- 「視力」（なし、0.5〜0.01、既定0.03）を選ぶと、画面全体をその視力相当に
  ぼかします。視力は見かけの角度（視角）で決まるため、画面に近づいても
  ぼやけは消えず、文字が大きく映る分だけ読みやすくなります。ぼかしの幅は、
  その視力で見分けられる最も細かい縞（視力1.0で1度あたり30周期）のコントラストが
  約5%まで下がる大きさにしています（視力0.03で視角約0.43°）。体験用の近似です。
  体験する人は、選んだ「画面までの距離」から画面を見てください。
- 「強さ」で効果を0〜200%に調整でき、「効果 ON/OFF」で見比べられます。

測定値から見えにくさへの換算は、医学的に確かめたものではなく体験用の仮定です
（`src/simulationModel.ts`）。

- 気付いた円の半径が0.5°以下の場所は見えにくさ0（健常とみなす）、1.5°以上の
  場所は見えにくさ1とし、その間は直線的に変えます。健常者と患者の測定記録を
  1件ずつ比べて決めた暫定値です（健常者は全地点0.22°以下、患者は中央値0.51°・
  最大1.12°）。
- 測定点の間は結果画面と同じ方法で補間し、最外周（15°）から外側5°で
  効果をなくします。
- 片眼の測定では、耳側15°付近の生理的な盲点に重なる地点を除きます
  （健常な眼にもあり、両眼で見ていれば気付かないため）。

## 技術構成

- React 19 + TypeScript + Vite
- 依存ライブラリなし（描画はSVG）

主なファイル:

| ファイル | 内容 |
| --- | --- |
| `src/types.ts` | 型定義、視角→ピクセル変換 |
| `src/App.tsx` | 画面遷移（設定 →（画面の大きさ合わせ）→ 測定 → 結果 / 履歴 / 見え方の体験） |
| `src/Setup.tsx` | 設定画面（眼の選択と説明） |
| `src/Calibration.tsx` | カードで画面の大きさを合わせる画面 |
| `src/calibrationStore.ts` | 画面の大きさ（1mmあたりのピクセル数）のlocalStorage保存・読み込み |
| `src/measurementPlan.ts` | 視角で固定した4つの同心円上の56地点と、試行の順序生成 |
| `src/Test.tsx` | 測定画面（56個の固定地点をランダム順に表示） |
| `src/Result.tsx` | 結果画面（56地点の測定値をグラデーション表示） |
| `src/fieldInterpolation.ts` | 測定地点間の補間（結果画面と見え方の体験で共通） |
| `src/Simulation.tsx` | 見え方の体験画面（カーソルのまわりに効果を重ねる） |
| `src/simulationModel.ts` | 測定値から見えにくさへの換算と、効果のマスク画像の作成 |
| `src/SimulationScenes.tsx` | 体験用のコードエディタ風・文書作成ソフト風の画面 |
| `src/History.tsx` | 測定履歴の一覧・削除・書き出し・読み込み画面 |
| `src/historyStore.ts` | 履歴のlocalStorage保存・読み込み、JSONファイルの作成・検証 |
