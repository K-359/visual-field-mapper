# 視野マッパー

レーベル遺伝性視神経症（LHON）などで中心が見えづらい方向けに、
「視野内のどの場所で、どの大きさのランドルト環の切れ目が分かるか」を
簡易的に測定・可視化するWebアプリです。

> ⚠️ 医療機器ではありません。結果は目安であり、診断には使えません。
> 正確な評価は眼科での視野検査を受けてください。

## 使い方

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

1. **準備** — 画面から約20cmの距離をとり、測定する眼（右眼・左眼・両眼）を
   選びます（距離は20cm固定）。
   初回は「画面の大きさを合わせる」で、カードを使って画面の実寸を合わせます
   （下記）。
2. **測定** — 画面中央の赤い丸を見続けます。固視点から視角2.5°・5°・10°・15°の
   4つの同心円上に、合計56箇所の固定地点があります（2.5°は8方向、それ以外は
   16方向）。各地点を1回ずつ、全56試行をランダムな順番で表示します。
   だんだん大きくなる黒いランドルト環の切れ目の向き（上下左右）が
   分かったら、その向きの矢印キーを押します。
   正しい向きを押すと、次の地点で拡大が始まります。Escでいつでも中止できます。
3. **結果** — 各地点で切れ目の向きを正しく答えたときの環の大きさから、
   56箇所の値を滑らかに補間したグラデーションマップを表示します。濃い赤ほど、
   その位置で切れ目が分かるまでに大きな環が必要だったことを示します。
   結果は自動的に測定履歴へ保存されます。

### ランドルト環で答える理由

以前は大きくなる赤い円に「気付いたらEnter」を押す方式でした。協力いただいた
LHONの方から「気付いてはいるが、本当に見えているか疑って迷う時間があり、
そこで誤差が出る」という声があり、正しく答えられたときだけを記録できる
ランドルト環に変えました。

- 環の太さと切れ目の幅は、標準的なランドルト環と同じく外径の1/5です。
  記録する値は、正しく答えた時点の環の**外側の半径**（視角、度）です。
- 切れ目の向きは試行ごとにランダムに決めます。違う向きを押したときは、環は
  そのまま大きくなり続け、切れ目の向きが別の向きに変わります（順に押して
  当てることができないようにするため）。違う向きを答えた回数は地点ごとに
  記録し、結果画面に合計を表示します。
- 押しっぱなしの連続入力は答えとして扱いません。
- 最大の大きさ（半径5°）でも分からない場所で先へ進めるよう、最大に達した後は
  どの矢印キーでも次へ進み、最大の半径を記録します。
- 4方向から選ぶため、分からないまま押しても1/4の確率で当たります。
  2回続けて正しく答えたら記録する方法もありますが、試行が増えると測定する
  本人の集中力が続かないため、1回正しく答えた時点で記録しています。

固視が外れにくいよう、環は測定中の1個だけを表示します。環は外側の半径0から
1秒あたり視角0.15°の速さで、全地点同じく最大半径5°まで拡大します。
内側の地点では環が中心の赤い丸（半径0.75°）に重なりますが、赤い丸は
白い縁付きで環の手前に描くので見失いません。

測定地点は画面の大きさではなく**視角（度）で固定**しているため、端末や
ウィンドウの大きさが違っても同じ網膜上の位置を測定します（範囲は
中心15°）。片眼の測定では、耳側15°付近の地点が生理的な盲点（マリオット
盲点）に重なるため、健常な眼でも気付きにくくなります。
最外周の環が最大まで広がっても画面から
欠けない大きさが必要で、ウィンドウが小さいと測定を一時停止して案内と
「全画面表示にする」ボタンを表示します。広げると、その地点を最初から
やり直します。試行ごとに地点は
変わりますが、測定に使う56箇所そのものは毎回同じです。

設定画面の「結果のサンプル」で、測定せずに結果画面のイメージを確認できます。

## 画面の大きさを合わせる（キャリブレーション）

視角を正しく表示するには、画面上の1mmが何ピクセルかを知る必要があります。
クレジットカード・キャッシュカード・マイナンバーカードなど、国際規格
（ID-1、85.60 × 53.98 mm）のカードを画面に当て、青い四角の大きさを
カードにぴったり合わせます（ボタン、スライダー、← → キーで調整）。

合わせた値はブラウザのlocalStorageに保存され、次回からはそのまま使います。
ブラウザの表示倍率（ズーム）や画面の大きさが変わったことを検知すると、
測定の前にもう一度合わせ直してもらいます。測定結果には、そのとき使った
1mmあたりのピクセル数も記録されます。

## 測定履歴

測定が完了すると結果はブラウザのlocalStorageに保存されます（最大300件、
古いものから削除）。設定画面・結果画面の「測定履歴」から過去の結果の
表示・削除ができます。ランドルト環にする前の赤い円で測定した記録も、
そのまま表示できます（履歴に「赤い円」と表示し、結果画面の説明も
赤い円の方式に合わせます）。

### 書き出し・読み込み（バックアップ）

履歴は端末のブラウザ内にしかないため、ブラウザのデータ消去や端末の変更で
失われることがあります。測定履歴の画面で、記録をJSONファイルとして
書き出せます。

- **すべて書き出す** — 全件を1つのファイルにまとめます
  （`visual-field-history-YYYYMMDD-HHMM.json`）。
- 各記録の **書き出す** — その1件だけを書き出します
  （`visual-field-YYYYMMDD-HHMM-right.json` など。日時は測定日時）。
- **ファイルから読み込む** — 書き出したファイルを履歴に戻します。
  すでに履歴にある記録（同じID）は二重に追加しません。形式が正しくない
  記録は読み込みません。読み込むと300件を超える場合は、古い記録が
  削除されることを確認してから読み込みます。

読み込んだ記録は通常の履歴と同じく「表示」で結果マップを見られます。

ファイルの形式:

```json
{
  "format": "visual-field-mapper-history",
  "version": 1,
  "exportedAt": "2026-10-23T05:30:00.000Z",
  "records": [
    {
      "id": "…",
      "savedAt": "…",
      "settings": { "distanceCm": 20, "pxPerMm": 3.78, "eye": "right", "stimulus": "landolt" },
      "results": [{ "xDeg": 2.5, "yDeg": 0, "radiusDeg": 1.2, "sampleCount": 1, "maxRadiusDeg": 5, "wrongCount": 0 }]
    }
  ]
}
```

`stimulus` は測定に使った刺激（`landolt`: ランドルト環、`circle`: 赤い円）、
`wrongCount` は正しく答えるまでに違う向きを答えた回数です。どちらも
ランドルト環にする前の記録にはなく、`stimulus` がない記録は赤い円とみなします。

## 見え方の体験（健常者向け）

LHONの方の見え方を健常者が体験できる画面です。
測定履歴の各記録の「体験する」から開きます。

- コードエディタ風・文書作成ソフト風の画面を表示し、カーソルの位置を中心に
  見えにくさを再現します。体験する人にはカーソルを見続けてもらい、
  カーソルを視線の代わりにします。
- OSのカーソルは小さくて見続けにくいため、体験画面の中では隠し、「文字の拡大」に
  合わせて大きくしたカーソル（拡大率100%で高さ24px、700%で168px）を代わりに出します。
  本文を読む画面なので、矢印ではなく文字入力のときのI字型にし、その中心がぼかしの中心です。
  実際のカーソルと一緒に動き、見続ける目印なのでぼかしません。
- 「ぼかしのもと」で、次の2つを切り替えられます。
  - **固定のぼかし（既定）**：測定結果を使わず、カーソルの位置が最も強くぼけ、
    離れるほど薄れる形にします。以前の試作（`origin/simulator` ブランチ）と
    同じ考え方です。患者さんの測定結果で試したところ、中心があまりぼけず
    意外と見えてしまったため、中心視野の見えにくさが分かりやすいこちらを
    既定にしています。
  - **測定結果**：開いた記録の測定結果から、場所ごとのぼかしを求めます。
    書き出したJSONを読み込めば、患者さんに測定してもらった結果で体験できます。
- 見えにくい場所ほど、強くぼかし、色を薄くします（明るさとコントラストは
  変えません。下げると暗い背景が灰色に浮いて見えるため）。
- 見えにくい範囲は視角で決め、今の画面の大きさ（キャリブレーション）と
  「画面までの距離」（15〜60cm、既定20cm）からピクセルに直します。視力が低い
  LHONの方は、画面に近づいて20cmほどで見ることが多いため、20cmを既定にしています。画面の大きさを
  合わせていない場合、範囲の大きさは目安になります。
- 「文字の拡大」で、コードや文書の本文を100〜1500%（既定700%）に拡大できます。
  LHONの方は文字をかなり大きくして使う（協力いただいた方は500%より大きくして
  いた）ため、実際のアプリの大きさより大きくしています。文書ページの余白は
  拡大せず、文字に使える幅を確保します。
- 体験に必要なのは拡大した本文なので、エディタのサイドバーやタブ、文書作成ソフトの
  リボンなどは置かず、どちらの画面も本文の部分だけにしています。
- ぼかしの大きさも視角で決めます。見え方は見かけの角度（視角）で決まるため、
  画面に近づいてもぼやけは消えず、文字が大きく映る分だけ読みやすくなります。
  体験する人は、選んだ「画面までの距離」から画面を見てください。
- 「効果 ON/OFF」で見比べられます。

### 固定のぼかし

- ぼかしの幅は「中心のぼかし × (1 − カーソルからの距離 ÷ ぼける半径)^1.6」で、
  ぼける半径より外側はぼかしません。1.6は以前の試作の既定値で、中心付近で速く
  薄れ、外側へ長く尾を引く形です（中心に一定の領域を作ると、一様にぼけた円に
  見えるため）。
- 「中心のぼかし」（0〜3.0°、既定2.0°）と「ぼける半径」（5〜40°、既定25°）を
  変えられます。どちらも視角なので、画面までの距離を変えても網膜上の大きさは
  変わりません。既定値は、20cm・700%で、カーソルの先の文字が読めない程度に
  しています。
- 手で決めた形で、医学的に確かめたものではありません。

### 測定結果

測定値からぼかしへの換算は、医学的に確かめたものではなく体験用の近似です
（`src/simulationModel.ts`）。

- ぼかしの幅は、その視力で見分けられる最も細かい縞（視力1.0で1度あたり30周期）の
  コントラストが約5%まで下がる大きさにしています（視力0.03で視角約0.43°）。
- 「強さ」で、ぼかしの幅を0〜200%に調整できます。
- 赤い円で測った記録では、「視力」（なし、0.5〜0.01、既定0.03）を選ぶと、
  画面全体をその視力相当にぼかします。ランドルト環で測った記録は各地点の視力が
  分かるため、この設定は表示しません。

**ランドルト環で測った記録**

- 正しく答えた環の切れ目の幅（外側の半径の0.4倍）を、その場所で見分けられる
  最小の角度（最小分離角）とみなし、その場所の視力を求めます。例えば半径1.8°なら
  切れ目は0.72°＝43分で、視力 約0.023です。協力いただいた患者さんの記録は
  中央値1.82°（視力 約0.023）で、普段の視力0.03とおおむね合っています。
  応答するまでの間も環は大きくなるため、実際よりやや見えにくめに出ます。
- 健常な目も周辺ほど視力が下がるため、体験する人の目がその場所でもともと
  見分けられない分は差し引き、足りない分だけぼかします。健常な目の視力は、
  中心で1.0、離心度2.5°ごとに最小分離角が1分ずつ増える（10°で視力0.2）という
  一般的な近似を使っています。健常な人の記録では、ほとんどぼけません。

**赤い円で測った記録（以前の方式）**

- 円に気付く大きさは視力と直接は結び付かないため、記録された半径が0.5°以下の
  場所は見えにくさ0（健常とみなす）、1.5°以上の場所は見えにくさ1（ぼかし0.7°）とし、
  その間は直線的に変えます。健常者と患者の測定記録を1件ずつ比べて決めた
  暫定値です（健常者は全地点0.22°以下、患者は中央値0.51°・最大1.12°）。

**どちらの刺激でも共通**

- 測定点の間は結果画面と同じ方法で補間し、測定範囲（最外周の15°）より外側は、
  同じ方向の最外周の値をそのまま延長します（効果の縁ができないようにするため）。
- 片眼の測定では、耳側15°付近の生理的な盲点に重なる地点を除きます
  （健常な眼にもあり、両眼で見ていれば気付かないため）。

## 技術構成

- React 19 + TypeScript + Vite
- 依存ライブラリなし（描画はSVG）

主なファイル:

| ファイル | 内容 |
| --- | --- |
| `src/types.ts` | 型定義、視角→ピクセル変換 |
| `src/App.tsx` | 画面遷移（設定 →（画面の大きさ合わせ）→ 測定 → 結果 / 履歴 / 見え方の体験） |
| `src/Setup.tsx` | 設定画面（眼の選択と説明） |
| `src/Calibration.tsx` | カードで画面の大きさを合わせる画面 |
| `src/calibrationStore.ts` | 画面の大きさ（1mmあたりのピクセル数）のlocalStorage保存・読み込み |
| `src/measurementPlan.ts` | 視角で固定した4つの同心円上の56地点と、試行の順序生成 |
| `src/Test.tsx` | 測定画面（56個の固定地点をランダム順に表示し、切れ目の向きを矢印キーで答える） |
| `src/LandoltRing.tsx` | ランドルト環の描画 |
| `src/landolt.ts` | 切れ目の向きと矢印キーの対応、向きのランダムな選択 |
| `src/Result.tsx` | 結果画面（56地点の測定値をグラデーション表示） |
| `src/fieldInterpolation.ts` | 測定地点間の補間（結果画面と見え方の体験で共通） |
| `src/Simulation.tsx` | 見え方の体験画面（カーソルのまわりに効果を重ねる） |
| `src/simulationModel.ts` | 固定のぼかしの形と測定値からの換算、効果のマスク画像の作成 |
| `src/SimulationScenes.tsx` | 体験用のコードエディタ風・文書作成ソフト風の画面（本文の部分だけ） |
| `src/History.tsx` | 測定履歴の一覧・削除・書き出し・読み込み画面 |
| `src/historyStore.ts` | 履歴のlocalStorage保存・読み込み、JSONファイルの作成・検証 |
